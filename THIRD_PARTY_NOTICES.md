# Third-party components

The procedural finger, gel sphere and textures are generated by this project. No hand reference image is redistributed. The pictures in `public/mp-ipad/finger-*.jpg` and `public/mp-ipad/tex/` were generated with GPT-6.2-Sol and processed by `scripts/bake-finger.py`.

| Component | Distribution | License / source |
| --- | --- | --- |
| Three.js | bundled browser code | MIT, [license](public/licenses/Three.txt), [upstream](https://github.com/mrdoob/three.js) |
| MediaPipe Tasks Vision | bundled PC tracker and locally served WASM | Apache-2.0, [license](public/licenses/MediaPipe.txt), [upstream](https://github.com/google-ai-edge/mediapipe) |
| MediaPipe Hand Landmarker Full, float16, version 1 | unmodified `public/models/hand_landmarker.task` | Apache-2.0, [official model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf), [task documentation](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker) |
| qrcode-generator | bundled PC tracker (QR code for the iPhone URL) | MIT, [license](public/licenses/qrcode-generator.txt), [upstream](https://github.com/kazuhikoarase/qrcode-generator) |
| ws | PC WebSocket server | MIT, [license](public/licenses/ws.txt), [upstream](https://github.com/websockets/ws) |

Model download: `https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`

Model SHA-256: `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1` (7,819,105 bytes).

The lockfile pins the installed dependency versions. `scripts/prepare-assets.mjs` copies the WASM runtime from that installed MediaPipe package, rather than loading a changing CDN runtime.
